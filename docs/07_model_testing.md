> **Обновление XAI (21.11.2026).** Для финальной ExtraTrees v4 реализован TreeSHAP с проверкой аддитивности: базовое значение + сумма SHAP-вкладов = прогноз класса мошенничества. В интерфейсе связанные закодированные и производные признаки суммируются по смысловым группам. В GroqCloud передаются только проверенные названия и вклады SHAP, без персональных данных. Модель и её порог не переобучались. Новый CI-прогон требуется для подтверждения внедрения; старые результаты score-delta относятся к предыдущей версии интерфейса.

**Данные:** только принятый v3, 7 000 синтетических транзакций; train 5 000 / validation 1 000 / test 1 000. Исходный проблемный CSV из вебинара 6 здесь не используется.

## Требования методички
Проверить модель и получить Accuracy/F1; составить тест-план из пяти типов, написать минимум пять pytest-тестов, выполнить их, заполнить таблицу PASSED/FAILED с пояснениями и сформулировать вывод. Методичка демонстрирует текстовую модель; мы адаптировали проверяемые свойства к табличному антифроду.

## Диагностический тест четырёх моделей
| Модель | PR-AUC validation | PR-AUC test | Recall test | FPR test |
|---|---:|---:|---:|---:|
| RF | 0.25328 | 0.22334 | 40.68% | 10.63% |
| CatBoost | 0.24352 | 0.21451 | 38.98% | 10.63% |
| LightGBM | 0.20174 | **0.25524** | 38.98% | **9.88%** |
| Blend | **0.25779** | 0.22161 | **42.37%** | 10.31% |

Test содержит 59 мошеннических операций. У Blend TP=25, FN=34; это недостаточно для реального антифрода. Пороги и вес Blend выбирались только на validation. Выбор модели **не** должен основываться на лучшем test PR-AUC. Сильная корреляция признака нового устройства с синтетической меткой и отсутствие новых пользователей в test — ограничения генератора.

## Вывод
Тестируемость и базовые свойства модели подтверждены локально; бизнес-готовность — **нет**. Для финальной ExtraTrees v4 модельный API E2E и CI уже подтверждены; браузерная проверка выполняется отдельно. Исторические метрики прежнего датасета (ROC-AUC ~0.94, F1 ~0.70) не относятся к v3.

## Финальная модель ExtraTrees v4: отложенная test-оценка

Сохранённый `extratrees-v4-artifact.zip` загружен локально с `joblib`, его `StandardScaler` и список one-hot колонок использованы без повторного fit. Для **validation (1 000; 41 fraud)** получены PR-AUC **0,342852**, ROC-AUC **0,803479**; для **test (1 000; 59 fraud)** — PR-AUC **0,237103**, ROC-AUC **0,697491**. Тестовая выборка не использована для выбора v4. Порог `review=0,049247396` выбран на validation при FPR ≤ 10% (FPR 7,61%, recall 53,66%). Не утверждаем, что этот порог пригоден для банка. В `tests/test_extratrees_v4_e2e.py` добавлены тесты загрузки, повторяемости и FastAPI; их выполнение в CI требует подтверждения.
