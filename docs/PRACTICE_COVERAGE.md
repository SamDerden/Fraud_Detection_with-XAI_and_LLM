## Единый протокол на принятом v3
- Основной набор: 7 000 размеченных транзакций; 3 776 warm-up отдельно; 220 пользователей; 321 метка фрода.
- Train 5 000 / validation 1 000 / test 1 000 по времени; **не** менять на 60/20/20.
- Из входных признаков исключены `is_fraud`, `split`, идентификаторы; порог и параметры подбирать по validation, не по test.
- Отдельный ablation без `is_new_device` и `device_age_days` — диагностический результат, не причина переписывать данные.
- Проблемный исходный датасет служит примером ошибок для вебинара 6; не смешивать его с v3.
- Синтетический антифрод не является банковской системой принятия решений.

## Невыполненные условия для честного «всё готово»
1. Полный проход по оригинальным методичкам всех вебинаров, включая задания с внешними ссылками и индивидуальную сдачу.
2. Воспроизводимый запуск сравнения четырёх моделей на **файле v3**, логирование результатов в MLflow.
3. Подтверждённые результаты pytest, Docker build, compose, smoke API и мониторинга именно после последних изменений.
4. Экспорт и проверка нового модельного артефакта на v3, SHAP и LLM end-to-end; живой LLM вызов только при наличии авторизованного ключа.
5. Финальные отчёт, презентация и ссылки на сдачу — отдельные артефакты, их нельзя объявлять выполненными без проверки.
