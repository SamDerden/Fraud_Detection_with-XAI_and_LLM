# Финальный контроль трёх моделей (21.11.2026)

**Выполнено локально:** CatBoost и LightGBM по 50 trials Optuna, одинаковые 7 engineered features, 3 expanding-window folds только внутри train 5 000; ExtraTrees v4 зафиксирована без перенастройки. Во всех folds scaler обучался только на training portion; test не открывался. Скрипт: [finalists_cv.py](../experiments/finalists_cv.py); [точные результаты JSON](../experiments/finalists_cv_results.json).

| Модель | Fold 1 | Fold 2 | Fold 3 | Средняя CV PR-AUC | Std | Validation PR-AUC |
|---|---:|---:|---:|---:|---:|---:|
| ExtraTrees v4, фиксирована | 0.244578 | 0.310537 | 0.247572 | 0.267563 | 0.030412 | 0.342852 (ранее) |
| CatBoost + FE, 50 trials | 0.257495 | 0.361076 | 0.216106 | **0.278226** | 0.060972 | 0.297847 |
| LightGBM + FE, 50 trials | 0.240907 | 0.269718 | 0.256933 | 0.255853 | **0.011787** | 0.253742 |

**Интерпретация:** CatBoost лидирует по среднему внутреннему CV на 0.01066 PR-AUC, но вдвое нестабильнее ExtraTrees и заметно уступает ей на отдельной validation. Всего 3 folds, превосходство статистически не доказано. Важно: ExtraTrees v4 ранее выбиралась по validation из 32 конфигураций, поэтому этот validation максимум оптимистичен. При заранее заданном критерии «средний CV» лидер CatBoost; при критерии «validation PR-AUC» — ExtraTrees. Нельзя заявлять безусловного победителя. **Для демонстрации оставляем уже интегрированную ExtraTrees v4; не меняем модель по test.** Все данные синтетические.
