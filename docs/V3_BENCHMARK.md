# Воспроизводимый benchmark v3 — 20.11.2026

**Статус:** локальный подтверждённый эксперимент на `transactions_v3.csv`; **не MLflow run**. Синтетические учебные данные, не банковская валидация. Split строго 5000/1000/1000 по времени; target, split и ID не включены в X. Seed 42. Порог выбран только по validation с лимитом FPR 10%; тест не участвовал в настройке.

| Blend CatBoost/LightGBM | **0.25779** | 0.22161 | **0.42373** | 0.10308 |

Вес CatBoost в Blend = 0.9, выбран по validation PR-AUC. В test 59 мошеннических транзакций; различия нестабильны на малой выборке. Нельзя выбрать LightGBM только потому, что его test PR-AUC оказался выше: test — финальная независимая оценка, не источник выбора гиперпараметров. По заранее заданной validation PR-AUC лучше Blend, но требуется анализ времени и бизнес-ограничений. Прототип API всё ещё использует старый артефакт CatBoost.

**Ограничения:** MLflow в локальной среде отсутствует, поэтому логирование MLflow не подтверждено. В GitHub Actions этот запуск не выполнялся. Нет независимой оценки на новых пользователях и реальных данных. Не объявлять все задания вебинаров завершёнными.

**Воспроизведение:** `PYTHONPATH=src python experiments/compare_four_models.py --data /path/to/transactions_v3.csv --mlflow-uri file:./mlruns` (нужен установленный MLflow). Локальный диагностический запуск использовал те же алгоритмы и параметры, но отдельный проверочный скрипт, поэтому числовое совпадение с основным скриптом ещё нужно подтвердить.


## Экспорт модели v3 и проверка SHAP (20.11.2026)

Локально обучен **CatBoost v3** на первых 5 000 транзакций; порог выбран по 1 000 validation; оценка проведена на 1 000 test (59 fraud). Это **демонстрационный кандидат**, а не финальный победитель. Сохранены `model.cbm` и `metadata.json` в отдельном архиве; в GitHub бинарный артефакт не добавлен.

- PR-AUC test: **0.21451**; ROC-AUC test: см. точное значение в `metadata.json` артефакта.
- Recall test: **23/59 = 38.98%**; FPR test: **100/941 = 10.63%**.
- Проверка аддитивности native CatBoost SHAP: `abs(sum(SHAP+base)-raw_prediction) = 8.88e-16` на одном примере — **пройдена**.
- Локально проверены форма и метаданные сохранённого артефакта; **полный HTTP smoke через FastAPI для этого нового артефакта пока не подтверждён**.
- Проверка `/predict`, `/healthcheck`, `/model-info` и неконсистентной истории добавлена в `tests/test_webinar_contract.py`. Её успешный прогон должен быть подтверждён GitHub Actions.

Доступные инструменты в локальной среде не содержат MLflow и Docker CLI. Поэтому **не выдаём локальное обучение за MLflow-трекинг или успешный Docker build**. CI в GitHub выполняет pytest и Docker build отдельно.


## Актуальное решение для защиты — ExtraTrees v4

**Выбрана ExtraTreesClassifier** с `n_estimators=200`, `max_depth=4`, `min_samples_leaf=6`, `random_state=42`, 13 исходными и 7 производными признаками. В углублённом ограниченном поиске (50–100 деревьев, 30+30 trials) достигнуто 0,312462; это не повторение победителя с 200 деревьями. [Артефакт v4](../extratrees-v4-artifact.zip) опубликован. **API, XAI, HTTP E2E и независимая новая test-оценка v4 не подтверждены.** Упоминания CatBoost/Blend и старых метрик в документе — исторический контекст, не итоговый выбор.
