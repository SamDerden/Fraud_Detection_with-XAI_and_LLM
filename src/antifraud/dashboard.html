◈ Параметры транзакции

Параметры — учебные примеры. Признаки нового устройства и ночной операции рассчитываются автоматически; время трактуется как UTC.

♧ Результат анализа

Выбери пример или измени параметры слева, затем нажми «Проверить транзакцию». Результат будет получен от реального API ExtraTrees v4 — никаких заранее нарисованных оценок.

Объяснение модели (влияние признаков)

Для ExtraTrees показано изменение оценки при замене одного закодированного признака его средним по train. Это диагностический метод, не SHAP и не причинное объяснение.

О модели

Сервис использует сохранённую модель ExtraTrees v4, обученную на 7 000 синтетических транзакций (train 5 000, validation 1 000, test 1 000). Это образовательный прототип, не банковская система.

Результат — некалиброванная оценка модели, а не подтверждённая вероятность мошенничества. Порог направления на ручную проверку выбран на validation с ограничением FPR до 10%; на реальных данных он не проверен. Автоматической блокировки платежей нет.
