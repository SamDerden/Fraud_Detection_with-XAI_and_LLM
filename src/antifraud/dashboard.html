♧ Результат анализа

Выбери пример или измени параметры слева, затем нажми «Проверить транзакцию». Результат будет получен от реального API CatBoost + LightGBM v3 — никаких заранее нарисованных оценок.

Объяснение модели (SHAP)

Для ансамбля приближённые вклады Shapley выражены в единицах оценки риска относительно базовой операции; для отдельного CatBoost — в log-odds.

О модели

Сервис использует сохранённую модель CatBoost + LightGBM v3, обученную на 7 000 синтетических транзакций (train 5 000, validation 1 000, test 1 000). Это образовательный прототип, не банковская система.

Результат — некалиброванная оценка модели, а не подтверждённая вероятность мошенничества. Порог направления на ручную проверку выбран по валидационной выборке. Автоматической блокировки платежей нет.
